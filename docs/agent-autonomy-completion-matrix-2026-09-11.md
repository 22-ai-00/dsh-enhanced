## 判定口径

- **生产 artifact** 指进入可发布包、安装器或正式 CLI/Host 路径的实现；它不等于该能力已经部署到真实用户环境。
- **真实运行证据** 只按实际发生的范围表述，例如本机真实模型调用、真实 Chromium、真实 Docker 或真实进程重启。测试 transport、fixture 模型、合成数据、fake systemd 和本地 HTTP server 一律标为工程证据，不冒充真实外部系统。
- **已验证** 包括账本对 WP01–WP03 的最终判定及本轮按原始条款关闭的 WP17；它表示该工作包的既定仓库验收门已满足，不表示真实 GitHub、Lark 云端、远程发布或长期收益都已验证。
- **实现中** 表示已经有生产路径 artifact，但至少一个工作包级成功标准仍缺证据。**待做** 表示尚无覆盖该工作包端到端交付要求的生产闭环；相邻基础设施不自动改变其状态。

当前按原始成功条件核验：**4 已验证 / 12 实现中 / 2 待做**。WP17 于 2026-09-13 完成原始三项验收并经独立复核关闭；该计数不等于产品交付完成率，禁止人为固定计数。

## 总结

当前已封闭的是可信学习输入与独立任务验收基线（WP01–WP03），以及按原始条款验收的安装工作包 WP17。WP04–WP15 均已有可运行的生产路径组件，但各自仍缺工作包级的真实收益、真实外部系统、部署类型或覆盖广度之一；WP16 和 WP18 还没有满足其端到端定义的生产闭环。因此，仓库当前不能宣称“18 项完成”，也不能把 `pnpm check`、fixture、合成留出、fake systemd、本地 HTTP transport 或局部真实模型运行合并推导为生产自治完成。
