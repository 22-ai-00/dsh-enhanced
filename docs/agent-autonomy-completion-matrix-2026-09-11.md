# 自治智能体 Prompt-to-Artifact 完成矩阵

审计日期：2026-09-11。本文把[智能与自治路线](agent-intelligence-autonomy-roadmap-2026-09-06.md)中的产品要求，逐项映射到[自治落地与验收账本](agent-autonomy-implementation.md)中的当前生产代码、最强证据、证据边界和最小剩余缺口。它是完成度索引，不替代两份权威文档，也不扩大其中的验收结论。

## 判定口径

- **生产 artifact** 指进入可发布包、安装器或正式 CLI/Host 路径的实现；它不等于该能力已经部署到真实用户环境。
- **真实运行证据** 只按实际发生的范围表述，例如本机真实模型调用、真实 Chromium、真实 Docker 或真实进程重启。测试 transport、fixture 模型、合成数据、fake systemd 和本地 HTTP server 一律标为工程证据，不冒充真实外部系统。
- **已验证** 沿用账本对 WP01–WP03 的最终判定；它表示该工作包的既定仓库验收门已满足，不表示真实 GitHub、Lark 云端、远程发布或长期收益都已验证。
- **实现中** 表示已经有生产路径 artifact，但至少一个工作包级成功标准仍缺证据。**待做** 表示尚无覆盖该工作包端到端交付要求的生产闭环；相邻基础设施不自动改变其状态。

当前总数严格保持：**3 已验证 / 13 实现中 / 2 待做**。

## 总结

当前已封闭的是可信学习输入与独立任务验收基线（WP01–WP03）。WP04–WP15 和 WP17 均已有可运行的生产路径组件，但各自仍缺工作包级的真实收益、真实外部系统、完整部署边界或覆盖广度之一；WP16 和 WP18 还没有满足其端到端定义的生产闭环。因此，仓库当前不能宣称“18 项完成”，也不能把 `pnpm check`、fixture、合成留出、fake systemd、本地 HTTP transport 或局部真实模型运行合并推导为生产自治完成。
