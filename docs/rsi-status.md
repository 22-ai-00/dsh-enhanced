## 目标与边界

普通使用驱动持续自迭代：认证任务与反馈 → 持久学习 → 能力候选 → 独立验证 → 有限采用 → 后续任务 → 观察与回滚。初始配置和授权后，主人不必逐次编排改进。

**完整普通使用闭环尚未验收；实验性版本先发布安装，长期学习效果在真实使用中持续验证。** 发布前的安装、运行就绪、安全边界与工程检查仍必须通过，不把发布成功等同于自迭代收益已验收。

- 已有认证反馈、持久记忆学习、原生任务调度、源码发现、新工具独立验收、有限采用及动态加载；后续真实任务的质量、成本、延迟与回归收益仍待验收。
- 本次 `0.1.49` 发布将默认 supervised 学习安装带入 npm，仍需可信配对、模型、有限预算、Linux systemd 和隔离构建。显式轻量安装与不启动选项保留；实际发布状态以[版本账本](../release-manifest.json)及 npm 元数据为准，不以版本准备完成代替发布成功。
- 当前锁及 peers 支持官方 npm latest **DSH `0.2.0-rc.2`**，该版本仍是预发布版，不称其为正式稳定版；安装先解析 latest，再固定受支持精确版本，不追踪 next。
