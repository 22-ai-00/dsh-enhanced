# RSI 当前状态

更新：2026-10-14。本页是唯一进展入口；验收见[合同](rsi-acceptance.md)，历史实施与生产迁移证据查 Git。

## 目标与能力边界

普通使用驱动持续自迭代：认证任务与反馈 → 持久学习 → 能力候选 → 独立验证 → 有限采用 → 后续任务 → 观察与回滚。初始配置和授权后，主人不必逐次编排改进。

**完整普通使用闭环尚未验收。** 实验性发布必须先通过安装、运行就绪和工程检查；发布成功不等于后续真实任务的质量、成本、延迟与回归收益已验收。

- 版本账本记录的已发布版本为 `0.1.49`，37 个包；支持的 DSH 精确版本为 `0.2.0-rc.2`（预发布）。发布与安装记录见[版本账本](../release-manifest.json)。
- 已发布能力包含认证反馈、持久记忆学习、原生任务调度、源码发现、新工具独立验收、有限采用与动态加载。`0.1.49` 的完整源码修复部署仍依赖 Linux systemd 与隔离构建。
- 生产 Home 的双 Host 和学习服务已通过新鲜启动就绪检查；既有身份、有限授权、暂停任务、会话模型及聊天历史保留。就绪不是长期进化收益证据。过期模型合同仍拒绝调用，未自动续期或切换模型。

## 当前交付

修复飞书安装时读取 Electron 专管 `desktop` profile 的错误：仅在 CLI 明确拒绝 Desktop 导出时，使用同版本 DSH 的只读配置组合接口，合并 bundle、profile 和 Home patch。继续检查 Delivery/owner/调度冲突；不能完整读取时仍拒绝接管，不忽略 Desktop。

下一交付是原生 macOS 学习：Node Host 由 launchd 管理，本机 Docker 容器承担候选隔离。目标覆盖持久记忆、新工具独立验证与动态采用，保留有限授权、安装恢复及运行时就绪检查；既有插件源码替换与发布仍沿 Linux 合同。当前 npm `0.1.49` 尚不包含这项移植。
